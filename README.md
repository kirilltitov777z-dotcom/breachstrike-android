# Breach Strike

Мобильный 3D-шутер от первого лица в духе Standoff 2 / CS для Android.
Написан с нуля на Java + OpenGL ES 2.0, без игровых движков и без AndroidX.

- Пакет: `com.breachstrike.game`
- minSdk 21 (Android 5.0), targetSdk 34
- Ориентация: горизонтальная
- APK: debug-сборка, подписана debug-ключом (для установки вручную)

## Скачать

APK лежит в разделе **Releases** этого репозитория (файл `app-debug.apk`).
Сборка и публикация выполняются только через GitHub Actions.

Установка: скачать APK на телефон → разрешить установку из неизвестных источников → установить.

## Что внутри

**Оружие.** 25 единиц: 5 пистолетов, 7 винтовок, 5 ПП, 2 дробовика,
2 пулемёта, 4 снайперские винтовки + 5 ножей. У каждого свои урон, темп,
магазин, перезарядка, разброс, отдача и дальность. Дробовики стреляют
дробью, снайперки имеют оптику.

**Скины.** 7 паттернов (Fade, Case Hardened, Doppler, Slaughter, Asiimov,
Hyper Beast, Dragon Lore), 5 степеней износа, 5 уровней редкости,
цены, инвентарь, экипировка в слоты, магазин за монеты.

**Карты.** Две оригинальные карты:
- `Foundry` — заводской двор, балкон на востоке, рампы, укрытия, точки A и B;
- `Neon Docks` — контейнерный лабиринт, catwalk над двором, точки A и B.

**Режимы.**
- 5v5 «Бомба»: закладка C4, таймер, раунды до 8 побед;
- Deathmatch: до 30 фрагов или 5 минут;
- Team Deathmatch: до 50 очков команды.

**Боты.** Три сложности. Боты ходят по waypoint-сети, видят игрока в
пределах дальности и угла, стреляют с задержкой реакции, которая зависит
от сложности.

**ELO и прогресс.**
- старт 1000;
- 8 рангов: Silver, Gold Nova, Master Guardian, DMG, Legendary Eagle, LEM, Supreme, Global Elite;
- формула: `K * (score - expected)`, K = 32,
  `expected = 1 / (1 + 10^((opp - my) / 400))`;
- бонусы за фраги (до +8), MVP (+4), объектив (+5);
- офлайн-матчи копят `pendingElo`, в шапке меню есть кнопка **SYNC ELO**;
- LAN-матчи начисляют ELO сразу;
- уровень, XP, монеты, статистика, лидерборд, кланы.

**LAN по Wi-Fi.** До 10 игроков. Хост показывает свой IP, остальные
вводят его в меню. Хост авторитетен: клиенты присылают позицию и луч
выстрела, хост считает попадания, здоровье, смерти и респавны, затем
рассылает снапшоты и события. Режим LAN — deathmatch на карте Foundry.

**Управление.**
- левый нижний угол — виртуальный стик;
- правая половина экрана — обзор свайпом;
- кнопки: огонь, прыжок, присесть, перезарядка, смена оружия, осмотр, оптика, закладка;
- пауза — кнопка в правом верхнем углу.

**Настройки.** Чувствительность, FOV, размер и стиль прицела, цвет,
инверсия Y, показ FPS, качество, громкость.

## Ассеты

В APK лежит настоящий HD-пак, сгенерированный процедурно скриптом
`tools/gen_assets.py` (Pillow + numpy), а не случайные байты:

- 7 PNG-текстур скинов 1536×1536;
- 19 PNG-текстур мира и ботов 1024×1024 (бетон, кирпич, металл, контейнеры,
  решётки, точки A/B, камуфляж и т.д.);
- 25 синтезированных WAV-звуков (выстрелы по категориям, перезарядка,
  шаги, попадания, закладка, взрыв, музыкальные аккорды раундов);
- иконка приложения.

Суммарно около 58 МБ исходных ассетов. CI проверяет, что APK больше
50 МБ и что внутри реально есть файлы ассетов, а не padding.

Текстуры хранятся в полном разрешении, но на телефоне декодируются
вдвое меньше (скины 768², мир 512²), чтобы не занимать 140+ МБ
видеопамяти.

## Сборка

Локально нужен Android SDK и Gradle 8.7+, JDK 17.

```bash
python3 -m pip install pillow numpy
python3 tools/gen_assets.py --out app/src/main/assets
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

CI (`.github/workflows/build.yml`) делает то же самое на `ubuntu-latest`,
проверяет размер APK, загружает artifact и публикует Release.

## Журнал падений

При необработанном исключении приложение пишет отчёт сюда:

```
/storage/emulated/0/Android/data/com.breachstrike.game/files/crash.txt
```

При следующем запуске текст ошибки показывается на экране.
Ошибки GL-треда также логируются в этот файл.

## Ограничения (честно)

- LAN — только deathmatch, без раундов, бомбы и командного счёта.
- Нет интернет-серверов, матчмейкинга и аккаунтов: ELO и статистика локальные.
- Модели оружия и ботов собраны из примитивов (боксы), это не glTF-модели.
- Текстуры процедурные, не фотографии.
- Боты используют waypoint-навигацию, без полноценного navmesh и укрытий.
- Игра проверена только компиляцией и генерацией ассетов; на физическом
  устройстве авторский прогон не выполнялся. Если что-то падает — пришли
  `crash.txt`.
- APK debug-подписан, не предназначен для Google Play.
